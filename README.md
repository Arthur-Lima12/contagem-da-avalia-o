# 📊 Contagem de Avaliações

Este projeto foi desenvolvido em Python para praticar estruturas de repetição, condicionais e contadores.

## 🎯 Objetivo

Receber os dados de 50 pessoas e contabilizar suas avaliações, classificadas como excelente, bom ou ruim.

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 💻 Visual Studio Code
- 🐙 Git e GitHub

## ⚙️ Funcionamento

O programa solicita o nome, a idade e a avaliação de cada pessoa. Ao final, contabiliza quantas pessoas escolheram cada opção:

- **1 — Excelente**
- **2 — Bom**
- **3 — Ruim**

## 📚 Conhecimentos praticados

- Variáveis e contadores
- Estrutura de repetição `for`
- Condicionais `if`, `elif` e `else`
- Entrada de dados com `input()`
- Conversão e comparação de valores
